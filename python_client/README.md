# GC Notify Python

A fork of https://gccode.ssc-spc.gc.ca/rdd2/gc-notify-python

---

Notifications API contracts rewritten as a simple Python client.

## Installation Example

- Download repository
- Install [Python 3.12](https://www.python.org/downloads/latest/python3.12/) or higher
- Open folder in terminal; Create a virtual environment, eg.:
```
python -m venv venv
```
- Build a package from the source materials using `bundle.cmd`, or import manually.
